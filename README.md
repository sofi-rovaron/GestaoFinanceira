# Sistema de Gestão Financeira 💰

Uma aplicação web full-stack dedicada ao controle de receitas, despesas e planejamento orçamentário. O projeto foi desenvolvido como parte de um projeto de extensão universitária na UNISAL.

## 🚀 Funcionalidades Principais

- **Autenticação Segura:** Login, cadastro e gerenciamento de sessão de usuários integrados via cookies.
- **Controle Orçamentário:** Fluxo completo para inserção, edição e remoção de entradas (receitas) e saídas (despesas).
- **Visão 360°:** Dashboard interativo para acompanhamento do saldo atual e planejamento financeiro com base em dados reais.
- **Interface Responsiva:** Design moderno e adaptável para qualquer tamanho de tela, projetado com base em protótipos de alta fidelidade.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Banco de Dados & Auth:** [Supabase](https://supabase.com/) (Gerenciamento de dados e autenticação segura)
- **Estilização:** [Tailwind CSS](https://tailwindcss.com/) & [shadcn/ui](https://ui.shadcn.com/)
- **Linguagem:** TypeScript / JavaScript
- **Prototipagem:** [Figma](https://www.figma.com/)

---

## 💻 Estrutura do Projeto

O desenvolvimento seguiu as melhores práticas de engenharia de software, utilizando rotas dinâmicas, fluxos de renderização eficientes no servidor (SSR/Client) e separação clara de responsabilidades entre a interface de usuário e os serviços de banco de dados.

---
Desenvolvido com foco em performance, portabilidade e impacto positivo na governança de dados pessoais.
